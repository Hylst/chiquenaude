# À propos de Chiquenaude

**Chiquenaude** est une adaptation du carrom, le billard indien traditionnel, développée
par **Geoffroy Streit** (alias **Hylst**).

## Le jeu

Le carrom est un jeu de plateau traditionnel d'Asie du Sud : on tire un gros palet
(le striker) d'une pichenette pour empocher les pièces de son camp dans les coins du
plateau, tout en gérant la reine, une pièce spéciale qui doit être capturée puis
confirmée.

Le nom « Chiquenaude » est le mot français pour désigner un petit coup donné avec le
doigt, exactement le geste qui propulse le striker.

## Le créateur

- Développeur d'applications, ancien graphiste et compositeur
- Adepte de rétrocomputing et de demoscene

## Stack technique

- React 19, TypeScript 5.9 (strict), Tailwind CSS 4
- Vite 7, vite-plugin-singlefile
- Moteur physique (collisions élastiques, rebonds, empochage) en fonctions pures
- Web Audio API pour la musique et les effets
